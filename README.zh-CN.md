# DIE Reborn 登陆器

[English](README.md) | **简体中文**

*Dead Island: Epidemic* 社区服务器 **DIE Reborn** 的登陆器。它负责安装和更新客户端补丁，显示服务器是否开服、有多少人在玩，并通过 Steam 启动游戏。

> **非官方爱好者项目**，与 Deep Silver、Stunlock Studios 及任何权利方无关。这里不分发任何游戏文件，需要你自己拥有游戏。

## 连接服务器

### 需要准备什么

- Windows 10 或 11，不用另装任何东西。
- Steam，开着并且已登录。
- 通过 Steam 安装好的 *Dead Island: Epidemic*。游戏已从商店下架，所以必须是你库里已经有的。

### 步骤

1. **下载** [最新发布](https://github.com/spardanviro/DIElauncher/releases/latest)里的 `DIE-Launcher.exe`，放在哪都行，放桌面也可以，不需要放进游戏目录。

   第一次运行时 Windows 可能弹出蓝色的"Windows 已保护你的电脑"，因为这个文件没有数字签名。点「更多信息」→「仍要运行」。

2. **运行它。**登陆器会自己在 Steam 库里找到游戏，并把目录显示在"客户端补丁"那一栏。找不到的话，大按钮会变成**选择游戏目录**：点它，选中游戏目录里的 `Dead Island Epidemic.exe`（在 Steam 里右键游戏 →「管理」→「浏览本地文件」可以打开游戏目录）。

3. **点"安装补丁"。**登陆器会下载补丁、校验，然后解压到游戏目录，几秒钟就好。这期间游戏必须是关着的。

4. **看服务器那一栏。**绿点加**已开服**表示服务器在线。三个数字分别是在线人数、对局中的人数、正在进行的局数。

5. **点"开始游戏"。**Steam 会启动游戏并自动登录：你的 Steam 账号就是你的身份，不用注册，也没有密码。

以后每次只需要：打开登陆器，点**开始游戏**。有新补丁时按钮会变成**更新补丁**，点一下，再点开始游戏。

### 大按钮的含义

| 按钮 | 含义 |
|---|---|
| **选择游戏目录** | 没在 Steam 里找到游戏，需要你手动指定。 |
| **安装补丁** | 游戏还没装补丁。 |
| **更新补丁** | 有新版补丁。 |
| **开始游戏** | 一切就绪。 |
| **游戏运行中** | 安装、更新、卸载之前要先把游戏关掉。 |
| **暂时无法获取补丁** | GitHub 和服务器都连不上，而且还没装过补丁。检查网络后点"检查更新"。 |

底部的链接依次是：检查更新、更改游戏目录、打开游戏目录、卸载补丁；右边是语言切换（中文 / English）。

## 连接到别的服务器

登陆器默认连的是 DIE Reborn 服务器。想去别人开的服务器，或者你自己开的服务器，需要告诉它地址。这个功能要求登陆器 **1.1.0 或更新的版本**。

1. 在 `DIE-Launcher.exe` 旁边新建一个文本文件，命名为 **`launcher.json`**。
2. 把服务器地址写进去（地址由开服的人告诉你）：
   ```json
   { "serverHost": "203.0.113.10" }
   ```
   域名也可以：`{ "serverHost": "play.example.org" }`。
3. 启动登陆器。服务器那一栏现在显示的是这个地址。还没装补丁的话点**安装补丁**，然后点**开始游戏**。

每次点"开始游戏"，登陆器都会让游戏连到这台服务器。想回到默认服务器：删掉 `launcher.json`，点**卸载补丁**，再点**安装补丁**。

注意文件名必须是 `launcher.json`，不能是 `launcher.json.txt`。在资源管理器里打开「查看 → 文件扩展名」可以确认。

`launcher.json` 支持这些设置：

| 设置 | 含义 | 默认 |
|---|---|---|
| `serverHost` | 服务器地址（IP 或域名） | DIE Reborn 服务器 |
| `statusPort` | 服务器状态接口的端口 | `8555` |
| `repo` | 从哪个 GitHub 仓库下载补丁，格式是 `用户名/仓库名` | `spardanviro/DIElauncher` |

怎么开服，在 **<https://github.com/spardanviro/DIE-Reborn>** 有一步一步的教程。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 服务器那一栏显示**未开服** | 服务器没开，或者你的网络连不到它，问一下开服的人。用了 `launcher.json` 的话，检查地址有没有写错。 |
| 下载很慢或者失败 | 登陆器先从 GitHub 下载，不行再从游戏服务器下载。两边都失败时，按钮下面那行字会分别写明原因。重试一次，或者换个网络。 |
| 提示"没有权限写游戏目录" | 右键登陆器 →「以管理员身份运行」。 |
| 明明关了游戏，却显示**游戏运行中** | 还有游戏进程没退出。在任务管理器里结束所有"Dead Island Epidemic"进程。 |
| 点"开始游戏"没反应 | Steam 没开或者没登录。先打开 Steam。 |
| 游戏打开了但提示连接错误 | 服务器没开，或者游戏不是通过登陆器或 Steam 启动的。 |
| 出现"登陆器有新版本" | 点"更新登陆器"，它会自己替换并重新打开。 |

## 补丁改了什么

`DIE-ClientPatch.zip` 会被解压到游戏目录：[BepInEx](https://github.com/BepInEx/BepInEx) 加载器、一个插件，以及一份指向服务器的 `ip.cfg`。插件让游戏改用普通的 Steam 会话票据登录（原版游戏用的票据只有原发行商能解开，社区服务器无从确认你是谁），并修了几个客户端自身的问题。

原版 `ip.cfg` 会备份成 `ip.cfg.orig`。**卸载补丁**只删除登陆器装进去的那些文件并还原原版，游戏本体从不改动。

登陆器的设置存在 `%LocalAppData%\DIE Reborn\`。它不在后台驻留，也不保存任何账号、密码或令牌。
